# Spatial: holes and counterarguments (red team)

17 Oct 2026, written 3:22–3:40 PM PT. Submission is due at 6:30 PM.
Verdict: **NEEDS WORK.** Today the table demo likely scores 12–14/25. The fixes in section 4 could raise that to about 17–19.

**The short version.** The marketplace and component count are strong. The thing judges score is weak: making an app in the headset with your body. In the current code, wiring, Play and Launch work only on the laptop. Nothing built after 1:42 PM has been run on a real Quest. Launched apps live in server memory on a laptop behind a tunnel.

What I checked: LOG.md, SPEC.md §41, VR-UX-SPEC §13, `web/registry/qa-report.md`, `mcp/`, the git log (to 82e21bc, 15:20), the Studio and VR source, and the live dev server through `curl`. Four research notes are cited by file name. I did not test in a headset, take screenshots, or run Claude Code against the MCP server.

## 6. After the hackathon: five changes that most raise the odds of real adoption

1. **Distribution before features.** Publish a shadcn-compatible registry and `npx spatial-mcp` on npm against a deployed site, so Claude Code, Cursor and v0 users can install our parts with no local path.
2. **Device-tested components as the product.** Automated behavior tests on Quest, AVP and Android XR (pinch, poke, hit size, an FPS budget per component), shown as badges. This answers "LLMs can write it" (27.8% behavioral pass) and "uikit kits exist".
3. **Turn IWSDK into a channel.** Export layouts and components to IWSDK/UIKitML and vanilla three.js, so Meta's 1M monthly WebXR users and its agent tooling bring people to us instead of past us.
4. **Wiring that does real logic.** Ranges, curves, events (button to action), and Web MIDI/OSC out for musicians. Treat the layout as a contract Claude can extend over MCP.
5. **Five real users before more components.** Sit with three React developers and two musicians. Measure time to first launched app and who comes back. Pick one persona, then build creator publishing and revenue share for them. Another option: laptop and headset editing the same scene at once, an open question the organizers asked.
