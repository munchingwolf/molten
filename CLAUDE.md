# molten

Before doing anything, `git pull` and read [LOG.md](LOG.md) (team status) and [SPEC.md](SPEC.md) (product spec). After finishing a task, making a decision, or changing anything shared, add an entry to the top of LOG.md's Log section and push it.

## Design System
Read DESIGN.md before visual or UI work: it defines the fonts, colors, spacing, and
aesthetic direction. Ask the user before departing from it. When reviewing or QA-ing
UI, flag code that doesn't match DESIGN.md.
